# Luffa V2 Metrics Dashboard (Sample)

This repository contains a sample analytics presentation exploring key usage and performance metrics for **Luffa V2**, a product within the Endless Protocol ecosystem.

## Metrics Covered
- Daily Active Wallets
- New Wallet Growth
- Storage Growth Over Time
- Files Uploaded Per Day
- Successful vs Failed Uploads
- Average Upload Time

## Data & Methodology
The analysis uses **synthetically generated datasets** modeled on expected Luffa V2 usage behavior.
While the values are illustrative, the **metrics design, dashboard structure, and interpretations are production-ready**.

## Future Scope
With access to live data from `scan.endless.link`, this framework can support:
- Interactive slicers (time, network, token, wallet type)
- Monthly ecosystem reporting
- Deeper wallet, validator, and contract analytics
